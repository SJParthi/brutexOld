📑 Pre-Open snapshot → Excel (.zip of yearly .xlsx)

Pick a date range and the symbols, then download a clean Excel your friend can open and sort. Numbers are lake-derived and match NSE: PREV. CLOSE = the prior day's official 1-day close, IEP = the 09:15 opening price, CHNG / %CHNG computed from them. The download is a .zip with one .xlsx per year, each holding one sheet per month; gainer rows are shaded green, losers red.

Two categories: 📋 All symbols — every selected symbol, every day (the “Minimum % change” box is ignored), sorted gainers→losers within each day. 📈 Top mover — per day, the single biggest absolute mover (gainer OR loser) whose |%CHNG| ≥ the minimum; days with no qualifier are skipped.

🚀 Run Sweep (brute-force backtest)

The ONE-CLICK web version of the brutex sweep-all terminal command — no typing required. BruteX first runs a probe-only data preflight + live estimate (trials · est. hours · est. GB) and asks you to confirm before anything starts; a not-ready lake refuses loudly naming the exact missing spans ("pull on /universe first") — it never silently sweeps over holes. Then it tries every strategy combo from the condition vocabulary across your downloaded index data, simulates each one's trades, scores them, and saves the ranked winners. Press 🪜 Run cascade below to keep only the ones that survive the nine anti-luck filters. Leave the boxes blank for the defaults: all 3 indices (NIFTY + BANKNIFTY on NSE, then SENSEX on BSE — run automatically back-to-back) · all 21 timeframes · 2020-01-01 → today.
