# brutex-calendar

The calendar-leaf DECISION laws in Rust (`DEC-RUST-CALENDAR-LEAVES-001`,
lane T18) — a byte-parity port of the pure decision plane of

* `brutex/calendars/observed_sessions.py` — the pure `classify_month_drift`
  admission/veto/cap core and the overlay-sidecar whole-accept/whole-reject
  validation (including the Python `==` int/bool/float VERSION PUNNING and
  the canonical-ISO-date round-trip entry law);
* `brutex/calendars/settle_evidence.py` — the full
  `validate_evidence_payload` truth table with every refusal message
  BYTE-IDENTICAL to the Python `ValueError` text, riding exact twins of
  CPython's `repr()`, `str(timedelta)` and the C-accelerated
  `datetime.fromisoformat` (quirks included — the goldens pin them).

Everything impure stays Python (I/O, `os.stat` memo, structlog, env tiers,
the sidecar merge/diff + serializer). Only ints/strings/bools/bytes cross
the FFI; a JSON parse-engine divergence (NaN/Infinity literals,
lone-surrogate escapes, deep nesting) is a LOUD ABSTAIN — the caller
degrades to the retained Python oracle.

## Layout

The house PyO3-kernel shape (`brutex-feed` / `trading-core`): pure-Rust rlib
core (`cargo test` links no libpython), the binding behind the optional
`python` feature, maturin mixed layout shipping
`brutex_calendar._brutex_calendar` behind the stale-wheel handshake shim.

## Parity evidence

`tests/goldens/*.json` are generated by `tests/goldens/generate_goldens.py`
running the REAL Python laws on the CPython 3.12 baseline (settle refusal
messages, `fromisoformat` verdicts + offset renderings, overlay loader
decisions, classify matrices); `tests/golden_parity.rs` replays every case
through the Rust port. Regenerate the goldens (and review the diff) in the
SAME commit as any Python-law change.

## Build

```sh
cargo fmt --check && cargo clippy --all-targets -- -D warnings && cargo test --release
# wheel (project venv active):
maturin build --release -m rust/brutex-calendar/Cargo.toml
```

Honest envelope (Golden Rule #10): a uniformity conversion — the Python
laws are microsecond-scale; no speedup is claimed, and the crate ships
consumed by nothing until the Python-side flip lands behind its own
default-OFF seam.
