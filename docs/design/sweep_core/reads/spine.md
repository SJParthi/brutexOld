### 2. Per-tuple driver: `run_supervised_grid` (brutex/engine/sweep_supervisor.py:480-)

Success → accumulate tallies, cache.record, checkpoint.record, `TUPLE_DONE`, `on_tuple`, `on_progress`.

### 4. Per-tuple body: `run_persisted_sweep` (brutex/engine/sweep_run.py:1157-1670)
Exact sequence:
1. `bars` non-empty check; `bars = maybe_guard_bars(bars)` (opt-in look-ahead barrier, identity when OFF — sweep_run.py:1296); `_direction_label` ("bull"/"bear").
2. `n_masks = count_combos(k, n_unique)`; refuse `> cfg.max_combos` (sweep_run.py:1300-1305).
3. `params = _canonical_params(cfg)` — {sl_paisa, tp_paisa, prior_n, proximity_bps, fib_anchor, start_equity_paisa} (sweep_run.py:626-687).
4. **Sentinel resume** (digest path, sweep_run.py:1313-1333): `_sentinel_resume(store.path, digest)` (sweep_run.py:840-884) — sentinel must exist, read valid, carry the digest, its `store_content_hash` must equal sha256 of actual store bytes, and if `sidecar_written`, the sidecar must pair. Paired → ONE `SWEEP_RESUMED` audit line, return summary with all-zero tallies + `resumed_complete=True`. Any failure → full redo.
5. `plan_rank_memory(n_masks, top_k, digest_path, mode, budget_bytes)` (sweep_run.py:1345) — refusal → `SweepMemoryBudgetError` (a `SweepComboError` subclass → tuple skip); `plan.bounded` engages columnar rank.
6. `SWEEP_START` audit line (sweep_run.py:1370).
7. `bar_bits`: `kernel.bar_bits` if a kernel was supplied (with `n_bars` + `fib_anchor` fail-fast guards, sweep_run.py:1388-1408), else `build_bar_bits(bars, proximity=cfg.proximity, prior_n=cfg.prior_n, fib_anchor=cfg.fib_anchor)` (Stage-1A, ONCE per tuple).
8. **Mask enumeration** (sweep_run.py:1438-1460): `for mask in iter_masks_k_of_bits(cfg.condition_bits, cfg.k)` — combo_mask.py:641-693: `itertools.combinations(sorted(set(bits)), k)`, per combination a Python-int OR-fold `mask |= 1 << p`, lexicographic order, u128 ints. Per mask: `enumerated += 1`; `has_conflict(mask)` (vocabulary/conflicts.py:115-126 — Python `any((mask>>a)&1 and (mask>>b)&1 for a,b in CONFLICT_PAIRS)`) → `conflict_pruned += 1; continue`; **digest path: `survivors.append(mask)` and NOTHING ELSE — no BLAKE3, no dedup probe** (lazy run-id, sweep_run.py:1443-1454). Legacy no-digest path only: `_lazy_run_id(mask)` eagerly + `dedup.seen(run_id)` → skip, else `survivors.append` + `survivor_run_ids.append`.
9. **Stage-1B min-hits prefilter** (sweep_run.py:1464-1474): `hits = kernel.count_hits(survivors)` (resident buffer) or `count_supermasks(bar_bits, survivors)` (free FFI); `kept = [m for m,h in zip(survivors,hits) if h >= cfg.min_hits]` (default `min_hits = MIN_TRADES`); `evaluated = len(survivors)`.
10. `run_id_of`: digest path → `_lazy_run_id` (pure `mask_run_id` = `combo_hash(strategy_id=f"mask:{mask:032x}", ...)` 9-field BLAKE3, sweep_run.py:368-426); legacy → dict of probe-time values.
11. If `kept`: `sim = _build_trade_sim(bars, bar_bits, cfg, direction_label)` (sweep_run.py:904-951) — one `ResidentTradeSim` per tuple; any non-MemoryError construction failure → `SweepComboError`; logs `sweep_run.trade_sim_path` (rust_active, n_bars, chunk_masks).
12. **Per-mask loop** — `_iter_mask_metrics(sim, kept, bars, bar_bits, cfg, direction_label, run_id_of)` (see §per-mask below). Batch arm: `pairs.append((mask, metrics))`; bounded arm: `columns.append(mask, metrics)` (drops the metrics object) + `owned_nbytes()` watermark → `SweepMemoryBudgetError` past budget (sweep_run.py:1518-1538).
13. Rank: batch → `rank_combos(pairs, overfit=cfg.overfit)` then `finalists = ranked[:top_k]` (sweep_run.py:1539-1544); bounded → `rank_survivor_columns(columns, ...)` + `_rebuild_bounded_finalists` (recompute ≤ top_k metrics through the SAME `_iter_mask_metrics` spine, order-checked; sweep_run.py:1099-1154, 1550-1558).
14. Persist: per finalist `ranked_combo_to_result_row(...)` → `store.append(row)` (sweep_run.py:1560-1576). **This projector RE-SIMULATES the finalist's trades via the pure-Python `simulate_trades` oracle** (deliberate; sweep_run.py:776-800): `mask_to_entry_signals(bar_bits, rc.mask)`, `bars_by_ts_first(bars, ...)` keep-FIRST timestamp dict (O(N_bars) per finalist), Decimal mean of real opens/closes, `round_money` → `avg_entry_price/avg_exit_price`. These bytes are part of the hashed store, so the kernel MUST reproduce the oracle's trades exactly.
15. `flush = store.flush()`; trial-stats sidecar `write_tuple_trial_stats` from `sidecar_sharpes` + fsum moments, written BETWEEN flush and mark (sweep_run.py:1578-1604); `marked = 0 if bypass_dedup else dedup.mark_many(...)` (digest path never marks — sweep_run.py:1614); `write_completion_sentinel` STRICTLY LAST (sweep_run.py:1618-1629); `SWEEP_FLUSH` + `SWEEP_COMPLETE` audit lines (exactly 3 per full sweep); `SweepRunSummary` returned.

### 5. THE per-mask loop: `_iter_mask_metrics` (brutex/engine/sweep_run.py:1021-1096)
The ONE chunked eval spine shared by batch rank, bounded columnar rank, AND bounded-finalist recompute:
- `chunk_size = _trade_sim_chunk_masks(len(bars))` = `max(1, min(256, (4<<20) // n_bars))` (sweep_run.py:183-204). Constants `_TRADE_SIM_CHUNK_MASKS = 256`, `_TRADE_SIM_CHUNK_CELLS = 4<<20`. Chunking is order-preserving + result-invariant (pinned by chunk-invariance tests).
- Per chunk:
  1. `chunk_pairs = sim.simulate_masks_with_exit_indices(chunk, direction=cfg.direction, stop_loss_paisa=cfg.sl_paisa, take_profit_paisa=cfg.tp_paisa)` — **FFI call #1** (see FFI section).
  2. Batch-contract guard: `len(chunk_pairs) != len(chunk)` → ValueError inside the try (sweep_run.py:1073-1078).
  3. `MemoryError` re-raises BARE at every level (OOM = global stop). Any other exception → `_reattribute_chunk_failure` (sweep_run.py:954-1018): re-runs the chunk one mask at a time through the pure-Python ORACLE `metrics_for_mask`; first mask that raises → `_combo_error(mask, run_id_of(mask), ...)` (fingerprint: `combo 0x%032x (run_id=...) in <inst>/<tf>/<dir> k=<k>: <exc>`, sweep_run.py:887-901); if EVERY mask passes → chunk-level `SweepComboError` naming the chunk; **oracle results are NEVER adopted** (engine provenance stays deterministic).
  4. `for mask, (trades, exit_indices) in zip(chunk, chunk_pairs, strict=True)`: `metrics = metrics_from_trades(bars, trades, start_equity_paisa=cfg.start_equity_paisa, tf_minutes=cfg.tf_minutes, exit_indices=exit_indices)`; any non-MemoryError raise → `_combo_error`; `yield mask, metrics`.

### 6. Per-mask metrics tail: `metrics_from_trades` (brutex/engine/sweep_driver.py:311-364)

- ON arm `_metrics_from_trades_via_kernel` (sweep_driver.py:465-538):

  - **Zero-trade mask short-circuits to `FLAT_DRAWDOWN_STATS = (0, 0.0, 0, 0.0)` with NO FFI** (the dominant share of the profiled tail — 66% of the fixture; rust_metrics.py:181).
  - `_exit_pairs(bars, trades, exit_indices)` (sweep_driver.py:367-397): supplied indices validated by `exit_indices_consistent` (exit_index.py:87-109 — O(trades): length match, in-range, `bars[idx].timestamp == trade.exit_ts`) → `[(idx, pnl_paisa)]` directly; inconsistent → warn-once `exit_indices_demoted` → `build_ts_index(bars)` O(N_bars) last-wins dict (NEVER to the Python oracle).
  - `_self_checked_drawdown` (sweep_driver.py:428-462): `drawdown_stats_via_kernel(n_bars, start_equity, exits)` — **FFI call #2** = `fno_math.sweep_drawdown_stats(n_bars, start_equity_paisa, exits: list[(idx, pnl)])` → 4-tuple `(max_dd_paisa:int, max_dd_pct:float, max_dd_bars:int, ulcer:float)` (rust_metrics.py:396+). Narrow except `(ValueError, TypeError, OverflowError)` → warn-once fallback; domain-validated by `_valid_drawdown`; **burn-in: first 16 kernel-served masks per process (`SELF_CHECK_SAMPLES`, process-global `_SELF_CHECK_REMAINING`) are bit-compared (struct.pack float keys, `drawdown_compare_key`) vs the Python `_drawdown_stats` oracle (O(N_bars) equity fold each); mismatch → `disable_kernel` process latch + ORACLE value ships**.
  - `compute_metrics_from_scalars(trades, len(bars), start_equity_paisa=, span_years=, drawdown=)` (metrics/compute.py:518-568) → `_compute_metrics_impl`: pure-Python single pass over trades (net_pnl, gross_profit/loss, winners/losers, MFE/MAE/holding sums, streaks, tail/skew/kurtosis, Sharpe/Sortino/Calmar/MAR/IR/Omega...) → frozen `ResultMetrics` dataclass (~40 fields; metrics/compute.py:170-240).

## (b) Data structures and shapes

- `slices: dict[(symbol:str, interval:str) -> list[CandleBar]]` — the whole-sweep bar memo (cli.py:5369). `CandleBar`: timestamp (aware datetime, UTC-stored), Decimal OHLC rupees, volume, oi.
- `SweepGridConfig` (sweep_orchestrator.py): frozen; axes tuples + provenance strings + prior_n/start_equity/max_tuples/max_combos/top_k/min_hits/overfit/stage3 knobs.
- `SweepTuple`: frozen (instrument, tf:Timeframe(label,minutes), direction:Side, k, sl_paisa|None, tp_paisa|None, proximity:ProximityParams|None, fib_anchor:FibAnchorKind); `.to_run_config(grid)` → `SweepRunConfig` (sweep_run.py:429-559, validated frozen slots).
- `bar_bits: list[int]` — per-bar u128 truth-vectors from Stage-1A `build_bar_bits` (60 bits live today; `MAX_VOCAB_BITS = 128`).
- masks: plain Python ints (u128 domain); `survivors: list[int]`, `kept: list[int]`.
- `ResidentSweepKernel` (sweep_kernel.py:77-193): `_bars: tuple[CandleBar,...]`, `_bar_bits: list[int]`, `_fib_anchor`, `_resident: ResidentBarBuffer`. `count_hits(masks) -> list[int]` delegates to `ResidentBarBuffer.count_supermasks`.
- `ResidentBarBuffer` (combo_mask.py:423-525): holds `fno_math.ResidentBars` (u64 Vec resident) XOR two-limb numpy uint64 arrays (`_bar_lo`, `_bar_hi`) for u128; raw tuple kept for on-demand limb rebuild.
- `ResidentTradeSim` (rust_trade_sim.py:256-738): slots `_bars` (tuple), `_bar_bits` (list), `_tf_minutes`, `_ts_certified` (bool, `bars_strictly_increasing` once at construction), `_call_fallback_warned` (set of reasons — warn-once per (instance, reason)), `_rust` (object|None — `fno_math.ResidentSweepSim` or `ResidentSweepSimU128`), `_rust_wide`/`_wide_unavailable`/`_rust_is_wide` (lazy u128 promotion state).
- Kernel input columns (derived in Python, `_derive_kernel_inputs` rust_trade_sim.py:405-462): `open_p/high_p/low_p/close_p: list[int]` (paisa via the SAME `stage1a._price_to_paisa` the Python walker uses), `forced: list[bool]` (session-aware forced-exit flags: per-IST-date `get_session_checked` → `forced_exit_seconds_for_session`, 1-slot date cache, `is_forced_exit_bar(ts_ist.time(), tf_minutes, secs)`), `session_days: list[int]` (per-bar IST `date.toordinal()` — the pending-entry cross-session drop gate R2-OC-2), plus `bar_bits`. Per-bar `bar.timestamp.astimezone(IST)` — O(N_bars) Python per ResidentTradeSim construction, paid **once per tuple** (NOT cached across tuples; only bar_bits/ResidentBars are cached in ResidentKernelCache).
- FFI trade record: 6-int tuple `(pnl_paisa, mfe_paisa, mae_paisa, holding_bars, entry_idx, exit_idx)`; the kernel returns `Vec<Vec<record>>` (one inner vec per mask, positionally aligned). Python maps each to `ClosedTrade(pnl_paisa, mfe_paisa, mae_paisa, holding_bars, entry_ts=self._bars[entry_idx].timestamp, exit_ts=self._bars[exit_idx].timestamp, direction)` (rust_trade_sim.py:715-738) — per-trade Python dataclass churn + 2 timestamp lookups.
- `simulate_masks_with_exit_indices` return: `list[tuple[list[ClosedTrade], list[int] | None]]` — exit indices emitted only under DOUBLE certificate (window ts strictly increasing AND per-mask `_monotonic` stream, rust_trade_sim.py:216-233, 687-713); else `None` (dict path serves).
- `ResultMetrics` (metrics/compute.py:170): frozen, ~40 fields — int paisa money, float|None ratios, drawdown 4-family, trade-quality counts, timing, distribution moments, Stage-4 DSR/PBO Nones.
- `pairs: list[(mask:int, ResultMetrics)]` (batch arm, ~1 KB/kept) vs `SurvivorColumns` (sweep_stream.py — columnar ~80-105 B/kept, `owned_nbytes()` exact watermark; with_overfit flag).
- `RankedCombo` (ranking/__init__.py:114): mask, metrics, composite_score, deflated_sharpe|None. `rank_combos` (ranking/__init__.py:471): `passes_gates` filter, optional overfit gate, 7 z-normalised composite terms (+opt-in 8th DSR term), sort key `(-composite, mask)` TOTAL order; **raises ValueError on duplicate masks among survivors**.
- `ResultRow` (results_store.py): run_id, labels, `mask_bits`, deflated_sharpe, money/metric family, `avg_entry_price/avg_exit_price` Decimal 2dp.
- `SweepRunSummary` (sweep_run.py:562-623): enumerated / conflict_pruned / skipped_dedup / evaluated / ranked / persisted / store_content_hash / backtested / minhits_dropped / trial_* / resumed_complete / sentinel_written.
- Dedup: `DedupSink` Protocol (seen + mark_many, sweep_run.py:275-293); `ComboDedup` re-keys hex→bytes over `OptionDedupIndex` (Bloom→LMDB exact); production digest path uses raising `DigestPathNoDedup` / `_NoDedup` instead.
- Run identity: `mask_run_id` = `combo_hash(strategy_id="mask:%032x" % mask, direction, instrument, tf, mode, params, data_snapshot_hash, indicator_version, code_commit_sha)` — 64-hex BLAKE3 (sweep_run.py:368-426).
- Audit lines: exactly `SWEEP_START`/`SWEEP_FLUSH`/`SWEEP_COMPLETE` per full tuple, `SWEEP_RESUMED` on sentinel short-circuit; grid layer adds `GRID_SWEEP_*`/`TUPLE_FAILED`; supervisor adds `SUPERVISOR_*`/`TUPLE_DONE`/`TUPLE_CACHE`/`TUPLE_SKIPPED_RESUME`.

## What crosses the Rust FFI boundary today (per tuple)

1. **Stage-1B count** — either `fno_math.ResidentBars(list(bar_bits))` built once per kernel-cache entry then `.count_supermasks(list(masks))` per call (only masks cross), or free `fno_math.count_supermasks_u64s(list(bar_bits), list(masks))` (re-marshals bar_bits) when kernel=None (combo_mask.py:373-415, 498-521). u64-native; any >u64 mask/bar routes to the two-limb numpy reference.
2. **Trade sim construction** — `fno_math.ResidentSweepSim(open_p, high_p, low_p, close_p, forced, session_days, bar_bits)` (or `ResidentSweepSimU128`), once per `ResidentTradeSim` = once per tuple with kept masks (rust_trade_sim.py:376-386).
3. **Trade sim batch** — per chunk (≤256 masks or 4Mi-cell budget): `rust.simulate_masks(list(masks), direction is Side.BUY, stop_loss_paisa, take_profit_paisa, sl_next_open: bool, tp_next_open: bool, tp_first: bool)` → per-mask list of 6-int records (rust_trade_sim.py:674-686).
4. **Drawdown family** — per non-zero-trade mask: `fno_math.sweep_drawdown_stats(n_bars, start_equity_paisa, exits: list[(exit_idx, pnl_paisa)])` → 4-tuple (rust_metrics.py:396+; default-ON since DEC-SWEEP-RUST-METRICS-DEFAULT-ON-001).
5. **blake3** (pip wheel) — `_tuple_digest` once/tuple; `mask_run_id` only for finalists + error fingerprints on the digest path.

## Pure-Python work that remains PER MASK (the conversion surface)

- `has_conflict(mask)` per enumerated mask (generator over CONFLICT_PAIRS).
- Mask int append + chunk slicing; `zip(chunk, chunk_pairs, strict=True)`.
- Per-trade `ClosedTrade` construction (+2 `self._bars[idx].timestamp` lookups) in `_to_trade_and_exit`; `_monotonic` scan per mask.
- `metrics_from_trades`: per-call env read (`os.environ.get`), envelope checks O(trades), `_exit_pairs` list build O(trades), and the whole `_compute_metrics_impl` single-pass metric assembly + `ResultMetrics` frozen-dataclass construction (~40 fields) — this is per-mask Python even on the kernel arm (only the drawdown 4-tuple is Rust).
- Batch arm retains `(mask, ResultMetrics)` tuples; bounded arm `SurvivorColumns.append` + `owned_nbytes()` per mask.
- Zero-trade masks: fully Python (no FFI at all): FLAT stats + `_empty_metrics`.
- Per-tuple (not per-mask) but Python: `_derive_kernel_inputs` (astimezone + paisa per bar), Stage-1A `build_bar_bits` on cache miss, `rank_combos`, finalist re-simulation via pure `simulate_trades` + `bars_by_ts_first`.

## (c) Invariants + failure modes

- **I1 Reproducibility (GR#4):** run identity = 9-field BLAKE3; the mask IS the strategy (`mask:%032x`). Engine choice (Rust vs Python) is NEVER in the identity or audit payload — path selection is structlog-only (sweep_run.py:169-172). Store bytes (incl. Decimal avg entry/exit from the finalist re-simulation) are content-hashed; the wired-vs-unwired store-hash golden pins Rust≡Python.
- **I2 Idempotence (GR#7):** digest path redo authority = the completion sentinel ONLY (write order: flush → sidecar → (no marks) → sentinel STRICTLY LAST). Absent/unpaired sentinel ⇒ FULL re-run with dedup bypassed — never a subset re-rank (MIGRATION.md #650). `load_or_create_store` preloads existing Parquet so a re-flush is byte-identical.
- **I3 Digest path never consults mask dedup:** `bypass_dedup = trial_stats_digest is not None`; launcher passes `DigestPathNoDedup` (raises on consult); parallel workers pass `_NoDedup` (raises). `skipped_dedup == 0` and `marked == 0` by construction on the production path.
- **I4 Error ladder:** `MemoryError` re-raises BARE everywhere (global stop). Chunk failure → oracle re-attribution → per-mask `_combo_error` fingerprint, or loud chunk-level error; oracle results never adopted. `SweepComboError` (incl. `SweepMemoryBudgetError`) → tuple skip + `TUPLE_FAILED` + non-zero exit + no sentinel/cache/checkpoint (deterministic redo). Everything else → grid abort.
- **I5 Chunk invariance:** chunk size affects only memory/FFI batching, never results (order-preserving; pinned by tests). Batch contract: exactly one (trades, exit_indices) pair per mask.
- **I6 Exit-index certificates:** indices emitted only if window ts strictly increase AND per-mask stream monotonic; demotion target is the bit-identical ts-dict path, NEVER the oracle — a demotion changes cost, never results.
- **I7 Kernel fallback law:** wheel state / envelope misses / flag state can never change results or error types — every fallback is the bit-exact Python oracle, warned once per (instance/process, reason). Fallback reasons: `wheel_missing`, `bar_bits_beyond_u128`, `price_out_of_envelope` (|paisa| > (2^63-1)//8), `mask_beyond_u128`, `stop_loss/take_profit_out_of_envelope`, `wheel_missing_u128`, metrics-side `equity_envelope_exceeded` (2^52), `kernel_error`, `kernel_disabled`, `self_check_mismatch` (autorevert latch), `exit_indices_demoted`/`exit_indices_not_monotonic`, `flag_unrecognised` (fails safe to OFF).
- **I8 Burn-in self-check:** first 16 kernel drawdown results per process bit-compared vs `_drawdown_stats`; mismatch latches kernel OFF process-wide and ships the ORACLE value.
- **I9 Domain normalisation at the seam:** HOLD direction and non-positive SL/TP raise identically on both arms (the kernel would accept 0; the wrapper rejects first — rust_trade_sim.py:607-616).
- **I10 Checkpoint = contiguous-clean-prefix:** frozen at the last clean index before the first failure; later successes short-circuit via the CACHE tier on resume.
- **I11 Bounded ≡ batch rank bit-for-bit:** same shared ranking internals (`composite_term_inputs`/`composite_scores`), same survivor order; finalist metrics recompute is bit-identical because the batch simulation is per-mask independent + deterministic.
- **I12 Audit O(1) in combo count:** exactly 3 hash-chained lines per tuple; never per mask.

## (d) Gotchas a Rust sweep-core conversion (moving the per-mask orchestration loop into PyO3) must NOT break

1. **Yield order is load-bearing.** `_iter_mask_metrics` must yield (mask, metrics) in exact input order — `_rebuild_bounded_finalists` pairs positionally (with an equality belt that raises `SweepComboError` on reorder, sweep_run.py:1133-1145), and rank determinism/tie-break assumes stable enumeration.
2. **Enumeration semantics:** `iter_masks_k_of_bits` = combinations over SORTED UNIQUE bits, lexicographic; duplicates in `condition_bits` are set-collapsed; k validated against n_unique. `count_combos` must agree with the max_combos refusal BEFORE Stage-1A.
3. **Conflict pruning order:** conflict check runs BEFORE the survivor append and counts `conflict_pruned` separately from `evaluated` (= len(survivors), INCLUDING Stage-1B drops). Tally arithmetic (`minhits_dropped = evaluated - len(kept)`, `backtested = len(pairs)`/`columns.n_kept`) feeds the trial-stats sidecar (ADR-0008 trial population N) and the audit payload — any drift breaks the frozen goldens and DSR statistics.
4. **Lazy run-id:** on the digest path NO BLAKE3 per enumerated mask — only finalists + error fingerprints. A Rust core that eagerly hashes per mask changes cost (fine) but MUST produce byte-identical ids from the same 9 canonical inputs incl. `canonical_trade_params` layout (key order irrelevant — JSON canonicalisation — but VALUES: proximity flattened to 3-int bps list or None; fib_anchor enum VALUE emitted unconditionally).
5. **Sharpe sidecar inputs:** `sidecar_sharpes` = per-kept-mask `metrics.sharpe_ratio` in kept order (batch) / `columns.sharpe_values()` (bounded); fsum moments must match bit-for-bit.
6. **Error fingerprint text is format-pinned:** `_combo_error` message format (`combo 0x{mask:032x} (run_id=...) in {inst}/{tf}/{dir} k={k}: {exc}`) and the chunk-failure message feed TUPLE_FAILED audit lines that tests pin format-identical across engine changes. The re-attribution protocol (oracle replay, never adopt) must survive.
7. **MemoryError is sacred:** must re-raise bare through any Rust orchestration layer (PyO3 must not wrap it) — OOM is a global stop, never a tuple skip; also never retried.
8. **Zero-trade fast path:** most masks close zero trades; today they cost NO FFI in the metrics tail (`FLAT_DRAWDOWN_STATS` + `_empty_metrics`). A conversion must keep +0.0 sign semantics (bit-level pinned) for the flat stats.
9. **Float bit-identity:** drawdown compare uses `struct.pack` bit patterns (signed zeros included); the 2^52 exactness envelope guard (`start + Σ|pnl| <= 2^52`) must stay a PRE-guard; span_years expression (`total_seconds()/(minutes_per_year*60)`, fallback `tf_minutes/minutes_per_year`) must be reproduced exactly; z-normalised composite fold must stay the shared internals (bounded ≡ batch pin).
10. **ClosedTrade timestamps:** trades carry entry_ts/exit_ts as the actual bar `datetime` objects (`self._bars[idx].timestamp`), consumed by `build_equity_curve` errors, `exit_indices_consistent`, and the finalist projector's `bars_by_ts_first` keep-FIRST dict. Duplicate-timestamp windows: indices withheld (`_ts_certified` False), dict path last-wins in `build_ts_index` but keep-FIRST in `bars_by_ts_first` — two DIFFERENT dup policies at two seams; do not unify.
11. **Warn-once discipline:** per-(instance, reason) for trade-sim call fallbacks; process-global memo for metrics fallbacks. A Rust loop must not turn these into per-chunk log floods, and must keep `sweep_run.trade_sim_path` (per tuple) + `sweep_run.bounded_rank_engaged` observability.
12. **The finalist re-simulation deliberately stays on the pure-Python `simulate_trades` oracle** (sweep_run.py:742-751) — an explicit non-goal to convert; its Decimal/round_money price anchors are hashed store bytes.
13. **`maybe_guard_bars`:** OFF must return the SAME object (identity) — the opt-in look-ahead barrier wraps bars in an index-guarded view when ON; a Rust core consuming raw arrays must preserve the guard's ability to observe reads (or route around it only when OFF).
14. **Env flag reads are per-call by design** (parallel workers own their env) — hoisting `sweep_rust_metrics_enabled()` out of the loop changes kill-switch semantics mid-tuple (currently a mid-run env flip could change the arm between masks — results identical either way, but tests may pin call counts).
15. **Bounded-rank watermark:** `columns.owned_nbytes() > plan.budget_bytes` checked AFTER EVERY append — a Rust accumulation must keep the exact owned-bytes accounting or the graceful `SweepMemoryBudgetError` (vs raw MemoryError) contract breaks.
16. **Stage-1B equivalence:** `kernel.count_hits` (resident) and `count_supermasks` (free) must remain bit-identical — the kept set decides the trial population. u128 masks route to the two-limb numpy reference; the u64 kernel must never silently truncate.
17. **Kernel/anchor guards:** kernel `n_bars` and `fib_anchor` mismatches must stay fail-fast ValueErrors (config error, grid abort) — NOT tuple skips.
18. **Supervisor kernel-cache capacity quirk:** `run_supervised_grid` sizes `ResidentKernelCache(capacity=len(grid.proximities))` (sweep_supervisor.py:654) — no fib_anchor factor (unlike run_sweep_grid). Preserve or consciously fix; results are identical either way.
19. **Parallel workers rebuild bar_bits** (no kernel_cache in `_run_tuple_in_worker`) and audit via `BufferedAuditCollector` replayed in canonical enumeration order — a Rust core must keep the audit sink injectable (real writer / buffered collector).
20. **`rank_combos` raises on duplicate masks** among gate-passing survivors — enumeration must never emit a duplicate mask within one tuple.
